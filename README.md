# TodoList


## 功能

- 日 / 周 / 月视图
- 待办可设开始、结束时间，以及分类（学习、工作、生活、重要，可自定义）
- 开始前 / 结束前倒计时提醒：到时间会弹出置顶提醒窗和系统通知
- 屏幕边上的浮球：显示今天未完成的待办数，圆环随任务剩余时间变短；单击可把组件浮到最前面
- 宽高、缩放、透明度、毛玻璃可调；可导出 JSON / CSV / 日历 .ics
- 数据只保存在本机，不需要联网

## 下载安装

1. 到右侧 **Releases** 下载最新的 `TodoList.zip`
2. 双击解压，把 `TodoList` 拖进「应用程序」文件夹
3. 本软件没有经过苹果认证，第一次打开会被系统拦截。打开「终端」运行下面这行后，再正常打开即可：xattr -dr com.apple.quarantine /Applications/TodoList.app
4. 第一次设置提醒时，系统会询问是否允许通知，请点「允许」

## 系统要求

macOS 12 及以上，Intel 和 Apple 芯片（M1 / M2 / M3…）都支持。
